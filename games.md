Links to Web/OpenGL builds of various Unity and Godot games I've built.

[Blue Rust](https://knockout-forge.itch.io/blue-rust) - Pixel art metroidvania platformer with steam punk aesthetics built in Godot, focusing on exploration and novel movement mechanics.

[Blue Rust: Memoria](https://brueland.itch.io/blue-rust-memoria) - An extension of Blue Rust built and submitted for Pirate Software Game Jam 15. 

[Reel Legends](https://brueland.itch.io/reel-legends) - A relaxing pixel art fishing simulator built in Unity and submitted for Score Space Jam #32. Overall ranking of 30 out of 71 submissions.

[Roll A Ball Unity Tutorial](https://brue.land/RollABall/) - WebGL build of the Unity tutorial "Roll A Ball" to test hosting games through GitHub Pages.

[Grow A Spine Experiment](https://brue.land/GrowASpine/) - Q-Learning experiment using Unity to demonstrate applications of ML models in game engines.

[Sid The Squirrel - CS6457 Final for GaTech](https://www.youtube.com/watch?v=l4dxJOaDrnA&ab_channel=WesleyBrueland) - Final project trailer submission for a 3D platformer developed as part of OMSCS CS6457 course.

[LORDFARQUADZILLA Music Game](https://brue.land/LORDFARQUADZILLA/) - An exploration of Godot using art and music assets from the band "Bilmuri".
